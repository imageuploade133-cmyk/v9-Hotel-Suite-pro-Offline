# **App Name**: Hotel Suite Pro

## Core Features:

- Dashboard Metrics: Display key performance indicators (KPIs) such as occupancy rates, revenue, and customer statistics. Generative AI can be used as a tool to analyze trends in this data, providing predictions on future performance.  The generative AI feature provides real-time insight on inventory, and occupancy.
- Booking Management: Enable creation, modification, and cancellation of bookings with real-time availability updates. Users can look at Hotel and POS customer data.
- Housekeeping Module: Manage room statuses (e.g., vacant, cleaning in progress, maintenance) and assign tasks to housekeeping staff.
- POS Integration: Process transactions, manage products/services, and generate sales reports.
- Stock Management: Keep track of inventory levels, set alerts for low stock items, and manage restock orders.
- Reporting and Analytics: Generate reports on bookings, revenue, occupancy, and other key metrics.
- User and Role Management: Configure fine-grained permissions to provide an increased level of security.

## Style Guidelines:

- Primary color: Deep Blue (#1A237E), providing a sense of trust and sophistication, reminiscent of established brands.
- Background color: Light Gray (#F5F5F5), a subtle, desaturated tint of the primary color for a clean, professional background.
- Accent color: Teal (#008080), an analogous color, is added to draw attention to interactive elements while maintaining brand consistency.
- Headline font: 'Space Grotesk', sans-serif; use 'Inter' for the body
- Consistent, modern icons from Lucide-react. Use solid icons for primary actions and outline icons for secondary actions.
- Clean, spacious layout with clear information hierarchy. Use a consistent grid system to maintain visual balance.
- Subtle transitions and animations to enhance user experience without being distracting. Use micro-interactions to provide feedback on user actions.
